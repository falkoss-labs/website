falkOSS labs is where the smaller projects of falkOSS – Falcon Lake Open Source Software live: plugins, tools, forks and experiments that are useful on their own but don't need an organisation of their own.

how it works

honest state

Every repository says in its README what state it is in and how much care it gets.

room to grow

When a project outgrows labs, it moves to an organisation of its own – old links keep working.

same principles

Free licences, no telemetry, in the open, non-profit – as everywhere at falkOSS.

contribute

Open an issue or a pull request in the repository you care about, or write to support@falkoss.org.
